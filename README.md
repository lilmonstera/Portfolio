# Portfolio

Lorena Gouws' coding portfolio - a collection of web development projects showcasing front-end and full-stack skills, from static HTML/CSS/JS sites to a Flask-powered web application.

## About

This repository hosts the source code for my personal coding portfolio along with several standalone projects built while learning and practicing web development. It includes my current portfolio site, an archived earlier version, and two featured projects: Clubtomix and Nucleus.io.

## Repository Structure

- portfolio/ - Current portfolio website (HTML, CSS, JavaScript) with home, proof of work, and contact pages
- OLD-PORTFOLIO/ - Earlier version of the portfolio, kept for reference
- Clubtomix/ - A golf tee-time booking web app built with Flask, Python, and SQLite
- Nucleus.io/ - A multi-page marketing style site (home, about, services, portfolio) built with HTML, CSS, JavaScript, and Tailwind

## Featured Projects

### Clubtomix - Book golf your way

A booking and management app that lets golfers register, log in, and keep track of their tee times in one place instead of juggling multiple systems.

- Front-end: HTML and CSS
- Back-end: Flask and Python
- Database: SQLite
- Features: user registration and authentication, a dashboard for managing bookings, and booking cancellation

### Nucleus.io

A multi-page site built with HTML, CSS, JavaScript, and Tailwind, including home, about, services, and portfolio pages.

## Getting Started 
1. To view the static sites (portfolio, OLD-PORTFOLIO, Nucleus.io), open the relevant index.html file in your browser.
2. To run Clubtomix locally, go into the Clubtomix folder, install the dependencies, and run app.py with Flask.
